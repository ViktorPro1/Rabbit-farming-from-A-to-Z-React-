# Документація проєкту

Ця папка містить технічну документацію сайту «Кролівництво від А до Я».

| Розділ | Вміст |
| --- | --- |
| [Архітектура](./Архітектура/) | Будова застосунку, маршрути й структура карток розділів. |
| [Аудити](./Аудити/) | Аудити коду та проєкту. |
| [Деплой](./Деплой/) | Публікація на Vercel і TWA-інструкція. |
| [Планування](./Планування/) | Дорожня карта проєкту. |
| [Розробка](./Розробка/) | Локальне середовище, стиль коду, внесення змін, безпека, контент, технічні рішення та діагностика проблем. |
| [Тестування](./Тестування/) | Unit-тести, E2E-тести та шпаргалка запуску. |

## З чого почати

1. Налаштуйте локальне середовище за [інструкцією](./Розробка/ENVIRONMENT.md).
2. Ознайомтеся з [гайдом розробника](./Розробка/DEVELOPER_GUIDE.md) і [структурою проєкту](./Архітектура/STRUCTURE.md).
3. Перед змінами перевірте [правила безпеки](./Розробка/SECURITY.md), [внесення змін](./Розробка/CONTRIBUTING.md) і [тестування](./Тестування/TESTING.md).

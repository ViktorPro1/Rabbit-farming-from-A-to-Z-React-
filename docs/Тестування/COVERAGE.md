# Звіт про покриття тестами (`coverage`)

Папка `coverage` містить HTML-звіт про те, які частини коду були виконані автоматичними тестами. Її створює Vitest із провайдером V8 після запуску:

```bash
npm run test:coverage
```

Звіт потрібен, щоб побачити неперевірені гілки, функції, оператори та рядки коду й визначити, де варто додати тести. Це технічний результат запуску тестів, а не вихідний код застосунку. Папка не потрапляє до Git: її вказано в `.gitignore`.

## Як переглядати

Відкрийте `coverage/index.html` у браузері. Головна сторінка показує підсумок для всіх файлів і посилання на звіти окремих папок та модулів.

У таблиці використовуються такі показники:

- **Statements** — виконані оператори коду.
- **Branches** — виконані варіанти умов, наприклад `if` або тернарних операторів.
- **Functions** — викликані функції.
- **Lines** — виконані рядки.

Відсоток показує частку покритого коду, а формат `виконано/усього` — точну кількість. У звіті конкретного файла непокриті місця позначені червоним, зокрема класами `cstat-no` та `missing-if-branch`.

## Структура та призначення файлів

| Файл або шлях                     | За що відповідає                                                                                                                                                                                                                      |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `coverage/index.html`             | Головна сторінка звіту з загальними показниками та переходами до папок.                                                                                                                                                               |
| `coverage/src/index.html`         | Підсумок покриття для коду в `src`.                                                                                                                                                                                                   |
| `coverage/src/<папка>/index.html` | Підсумок покриття для відповідної вкладеної папки, наприклад `components` або `lib`.                                                                                                                                                  |
| `coverage/src/**/*.tsx.html`      | Детальний звіт для конкретного React/TypeScript-файла: вихідний код, номери рядків і позначки покриття. Наприклад, `App.tsx.html`, `AppRoutes.tsx.html`, `CookieConsent.tsx.html`, `ErrorBoundary.tsx.html`, `WelcomePopup.tsx.html`. |
| `coverage/src/**/*.ts.html`       | Детальний звіт для TypeScript-модуля без JSX: наприклад, `usePublicPresence.ts.html`, `logError.ts.html`, `supabase.ts.html`.                                                                                                         |
| `coverage/base.css`               | Основні стилі HTML-звіту.                                                                                                                                                                                                             |
| `coverage/prettify.css`           | Стилі форматування підсвіченого коду в детальних звітах.                                                                                                                                                                              |
| `coverage/prettify.js`            | Підсвічує код на сторінках детальних звітів.                                                                                                                                                                                          |
| `coverage/sorter.js`              | Дозволяє сортувати колонки таблиць у звіті.                                                                                                                                                                                           |
| `coverage/block-navigation.js`    | Забезпечує навігацію клавіатурою між блоками коду.                                                                                                                                                                                    |
| `coverage/favicon.png`            | Значок вкладки для сторінок звіту.                                                                                                                                                                                                    |
| `coverage/sort-arrow-sprite.png`  | Графіка стрілок, що показують напрямок сортування таблиці.                                                                                                                                                                            |

Назви `*.html` у `coverage/src` повторюють структуру вихідного коду. Наприклад, `coverage/src/lib/supabase.ts.html` описує покриття файла `src/lib/supabase.ts`; це не його копія для редагування.

## Налаштування генерації

Налаштування розміщені у `vite.config.ts`, у секції `test.coverage`:

- `provider: 'v8'` — збирає дані про виконаний код засобами V8.
- `reporter: ['text', 'html']` — виводить короткий підсумок у термінал і створює HTML-звіт у `coverage`.
- `exclude` — не включає до розрахунку залежності, зібрані файли, тестові допоміжні модулі, декларації типів, CSS, скрипти та сторінки `src/routes/groups/**`.

Після нового запуску `npm run test:coverage` вміст `coverage` оновлюється відповідно до поточного коду та тестів.

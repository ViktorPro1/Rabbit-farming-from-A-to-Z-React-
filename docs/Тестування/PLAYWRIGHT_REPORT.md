# Звіт E2E-тестів (`playwright-report`)

У проєкті немає папки `.playwright-report` із початковою крапкою. Ймовірно, мається на увазі `playwright-report` — папка з HTML-звітом про виконання E2E-тестів Playwright. E2E (end-to-end) тести відкривають зібраний сайт у браузері та перевіряють користувацькі сценарії. Звіт потрібен, щоб швидко побачити, які сценарії пройшли або впали, скільки тривало їх виконання та, за наявності, переглянути технічні матеріали помилки.

Її створює Playwright після запуску:

```bash
npx playwright test
```

У цьому проєкті HTML-репортер увімкнено в `playwright.config.ts` параметром `reporter: 'html'`. Папка створюється лише після запуску E2E-тестів, тому її може не бути в чистій робочій копії.

## Як переглядати

Після запуску тестів відкрийте звіт командою:

```bash
npx playwright show-report
```

Вона відкриває головну сторінку звіту в браузері. Перед запуском E2E-тестів має бути доступна production-збірка:

```bash
npm run build
npx playwright test
```

Playwright згідно з `playwright.config.ts` запустить `npm run preview` і протестує сайт у Chromium за адресою `http://localhost:4173`.

## Структура та призначення файлів

Вміст формується автоматично та залежить від результатів запуску. Типова структура така:

| Файл або шлях                  | За що відповідає                                                                                                                                                                           |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `playwright-report/index.html` | Головна інтерактивна сторінка звіту: список тестів, їхній стан, тривалість і деталі помилок. Це файл, який відкриває `npx playwright show-report`. У поточному звіті це єдиний файл папки. |
| `playwright-report/data/`      | Може створюватися Playwright для даних і вкладень звіту, наприклад скриншотів, відео або trace. Її наявність залежить від результатів запуску та налаштувань. Не редагується вручну.       |

Не кожен запуск створює всі перелічені елементи. У конфігурації проєкту trace збирається лише для повторної спроби тесту (`trace: 'on-first-retry'`), тому за звичайного локального успішного запуску додаткових матеріалів може не бути.

## Пов’язані файли проєкту

| Файл                   | Призначення                                                                                                    |
| ---------------------- | -------------------------------------------------------------------------------------------------------------- |
| `playwright.config.ts` | Задає E2E-тести з папки `e2e`, HTML-репортер, Chromium, адресу preview-сервера та правила повторних спроб.     |
| `e2e/routing.spec.ts`  | Сценарії перевірки маршрутизації й закритих сторінок. Їхні результати потрапляють до звіту.                    |
| `e2e/pwa.spec.ts`      | Сценарії перевірки PWA: service worker, manifest та офлайн-екран. Їхні результати також потрапляють до звіту.  |
| `.gitignore`           | Виключає `playwright-report` із Git, оскільки це відтворюваний технічний результат запуску, а не вихідний код. |

Папку `playwright-report` не редагують вручну та не додають до репозиторію. Щоб оновити звіт, достатньо повторно запустити E2E-тести.

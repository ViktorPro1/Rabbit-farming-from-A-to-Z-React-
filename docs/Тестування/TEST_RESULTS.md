# Результати E2E-тестів (`test-results`)

Папка `test-results` містить технічні результати останнього запуску E2E-тестів Playwright. Вона потрібна насамперед для діагностики: коли тест не пройшов, у ній можуть з’явитися матеріали, що допомагають відтворити та зрозуміти проблему.

Її оновлює Playwright після запуску:

```bash
npx playwright test
```

Це не звіт для перегляду в браузері. Для загального перегляду результатів призначена папка `playwright-report` і команда `npx playwright show-report`. `test-results` зберігає первинні службові файли конкретного запуску.

## Поточний вміст

| Файл                          | За що відповідає                                                                                                                                                                                         |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `test-results/.last-run.json` | Службовий підсумок останнього запуску. Містить загальний статус (`passed`, `failed` тощо) та перелік тестів, які завершилися помилкою. Зараз у файлі вказано статус `passed`, а список помилок порожній. |

## Файли, які можуть з’явитися під час помилки

Назви вкладених папок залежать від назви тестового файла та сценарію. Playwright може створити такі матеріали:

| Файл або шлях                     | За що відповідає                                                                                                                                      |
| --------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| `test-results/<тест>-<сценарій>/` | Окрема папка для артефактів сценарію, що завершився помилкою.                                                                                         |
| `error-context.md`                | Текстовий опис стану сторінки на момент помилки, зокрема її структура та елементи інтерфейсу.                                                         |
| `test-failed-*.png`               | Скриншот сторінки в момент падіння тесту, якщо він був створений Playwright.                                                                          |
| `video.webm`                      | Запис виконання тесту, якщо в налаштуваннях або конкретному тесті увімкнено відео.                                                                    |
| `trace.zip`                       | Трасування дій браузера, мережевих запитів і кроків тесту. У цьому проєкті воно збирається лише на повторній спробі тесту: `trace: 'on-first-retry'`. |

Наявність цих файлів залежить від типу збою та налаштувань Playwright. За успішного запуску папка може містити тільки `.last-run.json`.

## Пов’язані файли проєкту

| Файл                   | Призначення                                                                                        |
| ---------------------- | -------------------------------------------------------------------------------------------------- |
| `playwright.config.ts` | Визначає папку з E2E-тестами, повторні спроби на CI та збирання trace при повторному запуску.      |
| `e2e/routing.spec.ts`  | Містить E2E-сценарії маршрутизації; при помилці їхні артефакти можуть потрапити до `test-results`. |
| `e2e/pwa.spec.ts`      | Містить E2E-сценарії PWA; при помилці їхні артефакти також можуть потрапити до `test-results`.     |
| `playwright-report/`   | HTML-звіт із підсумками, який може посилатися на матеріали помилок.                                |
| `.gitignore`           | Виключає `test-results` із Git, бо це відтворювані локальні результати запуску тестів.             |

Папку `test-results` не редагують вручну та не додають до репозиторію. Новий запуск `npx playwright test` оновлює її вміст.

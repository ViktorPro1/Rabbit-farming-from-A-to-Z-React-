# Папка `e2e`

`e2e` означає **end-to-end** («від початку до кінця»). Це автоматизовані тести, які відкривають зібраний сайт у справжньому браузері й перевіряють сценарії так, як їх проходить відвідувач. На відміну від unit-тестів, вони охоплюють взаємодію маршрутизації, інтерфейсу та PWA-функцій разом.

У проєкті для цих тестів використовується Playwright. Його налаштування містяться у корені в `playwright.config.ts`: тести запускаються у Chromium проти production-preview на `http://localhost:4173`.

## Вміст

| Файл                   | Призначення                                                                                                                                              |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `routing.spec.ts`      | Перевіряє доступність головної, «Породи» та «Гіда для новачків», сторінку 404 для невідомого шляху й показ форми входу для закритих маршрутів без сесії. |
| `pwa.spec.ts`          | Перевіряє реєстрацію service worker, доступність і назву `manifest.webmanifest`, а також екран «Немає інтернету» в офлайн-режимі.                        |
| `tsconfig.json`        | TypeScript-налаштування саме для E2E-тестів.                                                                                                             |
| `tsconfig.tsbuildinfo` | Технічний кеш TypeScript; його не редагують вручну.                                                                                                      |

## Запуск

Спершу потрібна production-збірка, бо E2E-тести перевіряють саме її:

```bash
npm run build
npx playwright test
```

Playwright сам запустить `npm run preview` згідно з конфігурацією. Після виконання HTML-звіт можна відкрити командою:

```bash
npx playwright show-report
```

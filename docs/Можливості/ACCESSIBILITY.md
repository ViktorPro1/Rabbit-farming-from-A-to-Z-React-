# Доступність

> Розділ технічної документації. Короткий огляд проєкту — у [головному README](../../README.md).

Розмір шрифту платформи частіше налаштовують читачі старшого віку — за
статистикою дописів понад 75% авдиторії 50+.

Реалізовано:

- Кнопка "Aa" в шапці платформи перемикає три рівні масштабу тексту
- Вибір зберігається між візитами (localStorage)
- Масштабування діє на весь сайт, без винятків для окремих сторінок

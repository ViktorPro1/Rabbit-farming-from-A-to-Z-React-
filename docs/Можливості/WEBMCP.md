# WebMCP (інструменти для ШІ-агентів)

> Розділ технічної документації. Короткий огляд проєкту — у [головному README](../../README.md).

Експериментальна підтримка **WebMCP** — нового API браузера, який дозволяє сайту надавати ШІ-агентам структуровані інструменти замість розбору сторінки «наосліп». Це прогресивне покращення: у браузерах без підтримки WebMCP нічого не змінюється, сайт працює як раніше.

Реалізовано:

- Реєстрація інструментів через `document.modelContext` із запасним варіантом `navigator.modelContext` (Chrome 149)
- Інструмент `search_rabbit_articles` — пошук по каталогу публічних сторінок за назвою, описом і ключовими словами, до 10 результатів
- Інструмент `open_site_page` — відкриття публічної сторінки за внутрішнім шляхом, лише зі шляхів із каталогу сайту
- Лише читання і навігація: розділи особистого кабінету та адмін-панель не пропонуються й не відкриваються
- Каталог сторінок підвантажується ліниво (`import()`), тому не збільшує основний бандл
- Компонент `WebMCPRegistrar` усередині `BrowserRouter`, коректна реєстрація й зняття реєстрації (React StrictMode)
- 12 unit-тестів (`webmcp.test.ts`, `webmcpCards.test.ts`)
- Перевірено в Chrome з увімкненим прапорцем WebMCP: обидва інструменти видно через `document.modelContext.getTools()`, пошук повертає реальні сторінки

**Статус:** WebMCP — експериментальне API (у Chrome доступне як origin trial), його назви й поведінка можуть змінюватися.

# AppRoutes — де який маршрут лежить

Довідник тільки по розбиттю `AppRoutes.tsx`. Раніше все було в одному файлі на 500+ рядків, тепер розкладено на 12 файлів. Загалом — **197 маршрутів** (+ catch-all `*` → 404).

---

## `src/routes/AppRoutes.tsx`

Головний файл (~60 рядків). Не містить самих маршрутів, лише збирає всі групи докупи, обгортає в `<Suspense>`, викликає `usePageMeta()`, в кінці — catch-all `*` → `NotFound`.

---

## Як шукати конкретний маршрут

1. Дивишся на назву сторінки/шлях (напр. `/mastitis`) і по темі здогадуєшся, яка це група (мастит → розділ "РОЗВЕДЕННЯ" → `breedingRoutes.tsx`).
2. Якщо не певен — пошук по всій папці `src/routes/groups/` за назвою шляху (напр. `Ctrl+Shift+F` → `"/mastitis"`) миттєво знайде потрібний файл.
3. Кожен файл невеликий (30–100 рядків) — можна просто відкрити й пробігти очима.

## Як додати новий маршрут

1. Визначаєш, до якої тематичної групи він належить (або яка найближча за старою назвою розділу з таблиці вище).
2. У відповідному файлі групи додаєш `const NewPage = lazy(() => import("../../pages/NewPage/NewPage"));` зверху та `<Route path="/new-page" element={<NewPage />} />` у відповідному місці JSX.
3. Якщо сторінка потребує сесію (як `/calculator` чи весь `cabinetRoutes.tsx`) — використовуй патерн `session ? <Component session={session} /> : <Auth />`, і не забудь що тоді файл групи має бути функцією `getXRoutes(session)`, а не константою.
4. Нічого міняти в `AppRoutes.tsx` не потрібно, якщо група вже існує і вже імпортована.

## Якщо потрібна абсолютно нова група (нова велика тема)

1. Створити новий файл у `src/routes/groups/`, за зразком будь-якого існуючого (структура: lazy-імпорти зверху, потім `export const xRoutes = (<>...</>)` або `export function getXRoutes(session) {...}`).
2. Імпортувати його в `AppRoutes.tsx`.
3. Додати `{xRoutes}` (або `{getXRoutes(session)}`) усередину `<Routes>`.

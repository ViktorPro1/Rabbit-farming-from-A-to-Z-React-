# Взаємодія проєкту «Кролівництво від А до Я» з ШІ (100% безкоштовно / 0$ витрат)

Цей документ фокусується виключно на **зовнішній взаємодії сайту зі штучним інтелектом** (LLM Discovery, GEO, AI-пошуковики, індексація мовними моделями та агенти розробки) **без використання платних API та без впровадження платних чат-ботів**.

---

## 1. Суть концепції «Взаємодія з ШІ» (0$ витрат)

Сайт виступає як **безкоштовна структурована база знань для всіх світових ШІ-систем** (ChatGPT, Perplexity, Claude, Gemini, DeepSeek, Google AI Overviews, Apple Intelligence).

Мета: коли будь-який користувач у світі запитує у ChatGPT чи Perplexity:
> *"У кролика здувся живіт, що робити?"* чи *"Норми годівлі кролиць породи Полтавське срібло"*,

ШІ-модель має взяти точну інформацію саме з цього сайту, процитувати його і дати пряме посилання на сторінку.

## 2. Аудит файлів: що вже є

| Файл | Статус | Роль у безкоштовній взаємодії |
| :--- | :--- | :--- |
| **`AGENTS.md`** (корінь) | Актуальний | Інструкція для AI-помічників розробника (Antigravity, Cursor, GitHub Copilot). Дозволяє AI-агентам безкоштовно розуміти правила та стек проєкту. |
| **`public/llms.txt`** | **Застарілий** | Стандартний файл-інструкція для мовних моделей. Зараз містить лише 127 посилань (за червень 2026), а на сайті вже 191 сторінка. |
| **`public/llms-full.txt`** | **Застарілий** | Розширений текстовий зліпок бази знань для глибокого аналізу ШІ. Також не оновлювався з червня. |
| **`public/.well-known/ai-catalog.json`** та **`ard.json`** | Присутні | Каталоги сторінок сайту з типовими пошуковими запитами для AI-агентів каталогів. |
| **`index.html`** | Реалізовано | Містить зв'язок `<link rel="describedby" href="/llms.txt">` та базову мікророзмітку `Schema.org`. |
| **`src/sw.ts`** | Реалізовано | Виключає `llms.txt`, `robots.txt`, `sitemap.xml` з кешу Service Worker. |
| **`public/robots.txt`** | **Неповний** | Не містить директиви на `llms.txt` та не декларує правила для конкретних AI-ботів. |

## 3. Які файли потрібно додати (усе 100% безкоштовно)

### 1. `scripts/generate-llms.mjs` (Критично)
* **Чому потрібен:** Зараз `llms.txt` застиг на відмітці 127 сторінок. Понад 60 нових розділів сайту (лікування, аптечка, нові породи, облік) ШІ-системи просто не бачать через `llms.txt`.
* **Як працює:** Працює під час локальної збірки або на безкоштовному білді Vercel (`npm run build`). Автоматично зчитує `src/prerender-routes.ts` і генерує свіжий `public/llms.txt` перед кожним деплоєм (0$ витрат, без зовнішніх сервісів).

### 2. Оновлений `public/robots.txt` (Рекомендовано)
* **Чому потрібен:** Щоб AI-краулери знали, де шукати готовий контекст для швидкого парсингу, і не витрачали зайві запити.
* **Що додати:**
  ```text
  # AI/LLM Context Reference
  # llms.txt: https://rabbit-farming-from-a-to-z-react.vercel.app/llms.txt
  # llms-full.txt: https://rabbit-farming-from-a-to-z-react.vercel.app/llms-full.txt

  # Дозвіл для AI-краулерів (пошук та цитування)
  User-agent: GPTBot
  Allow: /

  User-agent: PerplexityBot
  Allow: /

  User-agent: ClaudeBot
  Allow: /

  User-agent: Google-Extended
  Allow: /

  User-agent: Applebot-Extended
  Allow: /
  ```

### 3. `CLAUDE.md` та `.cursorrules` (Корисно для розробки)
* **Чому потрібні:** Якщо для роботи над проєктом використовуються безкоштовні версії Claude Code або Cursor, ці файли просто містять посилання на `AGENTS.md`, зберігаючи всі жорсткі правила проєкту (без Next.js, українська мова, нічого не видаляти).

## 4. Перспективи безкоштовної взаємодії з ШІ

### А. GEO (Generative Engine Optimization) — Пошукова перевага
* Користувачі все частіше запитують інформацію не в традиційному пошуку Google, а в Perplexity, ChatGPT Search або отримують відповіді через Google AI Overviews.
* Маючи актуальний `llms.txt` та семантичну структуру, проєкт стає **головним і найнадійнішим джерелом для всіх LLM** в україномовному секторі кролівництва.

### Б. Безкоштовний трафік без реклами
* Мовні моделі, формуючи відповідь, прикріплюють джерела (посилання на сайт). Це дає постійний притік цільових фермерів абсолютно безкоштовно.

### В. Сумісність із зовнішніми ШІ-асистентами користувачів
* Будь-який фермер може дати посилання на `https://.../llms.txt` своєму безкоштовному ChatGPT чи Claude і запитати: *"Проаналізуй цей довідник і склади мені план вакцинації на осінь"*. Сайт надає структуровану відповідь за лічені секунди.

## 5. План дій

1. Створити скрипт `scripts/generate-llms.mjs` для автоматичної підтримки актуальності `llms.txt` при кожній збірці.
2. Доповнити `public/robots.txt` блоком для AI-пошуковиків.
3. Додати `scripts/generate-llms.mjs` у команду збірки у `package.json` (`npm run build`).

# Розбиття Statistics.tsx: що де лежить і як злити гілку

Було: один файл на 2543 рядки. Стало: головний файл 147 рядків і 27 маленьких файлів.
Вигляд сторінки, тексти, класи CSS і запити до бази не змінені.

## 1. Що де є

Головне:

- `Statistics.tsx` - сторінка: вибрана вкладка, заголовок, збирає все докупи.
- `useStatisticsData.ts` - завантаження основних даних і помилки (колишній великий useEffect).
- `useWeighingData.ts` - окреме завантаження вкладки "Зважування" і її розрахунки.
- `fetchStatistics.ts` - самі запити до Supabase (7 паралельних, окроли, зважування), усі з `.range(0, 9999)`.

Розрахунки (без React, прості функції):

- `breedingStats.ts` - статистика самок, самців, пар, кліток; невдалі окроли; точність окролу.
- `monthly.ts` - підсумки по місяцях для вкладки "Огляд".
- `utils.ts` - допоміжне: медалі, назви місяців, підрахунок голів, цикли зважування, групування по місяцях.
- `constants.ts` - списки місяців, підписи, список вкладок, тексти помилок, ліміт 9999.
- `types.ts` - усі типи в одному місці.

Компоненти в `components/`:

- Картки: `RabbitCard`, `PairCard`, `CageCard`, `AccuracyCard`, `FailureCard`.
- Вкладки: `SlaughterTab`, `SalesTab`, `FailuresTab`, `OverviewTab`, `WeighingTab`, `BreedingCards` (самки, самці, пари, клітки, точність).
- Графіки: `BarChart`, `MiniBar`, `OverviewChart`, `TabCharts`.
- Загальне: `SummaryCards`, `TabBar`, `EmptyState` (порожній стан, раніше був скопійований 9 разів).

## 4. Що саме перевірено

- Тести: 8 ваших тестів проходять на старому і на новому коді.
- TypeScript (tsc) без помилок, Prettier без зауважень.
- Окремий порівняльний тест (тимчасовий, у проєкт не входить): старий і новий код з однаковими даними, усі 10 вкладок, 6 сценаріїв (повні дані, порожньо, без злучок, помилка sales, помилка litters, помилка weighings). HTML і список запитів до бази збігаються символ у символ. Навмисна поломка назви місяця цей тест помітив.
- Вигляд у браузері окремо не перевіряв: CSS не змінювався, а HTML ідентичний.

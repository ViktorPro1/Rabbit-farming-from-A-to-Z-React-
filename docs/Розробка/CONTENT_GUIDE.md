# Робота з контентом

Сайт містить довідкові матеріали про кролівництво. Точність важливіша за швидке наповнення: не додавайте неперевірені факти, дозування, діагнози або ветеринарні рекомендації.

## Де зберігаються дані

- Картки головних тематичних розділів — `src/data/sectionCards/groups/`.
- Дані про породи — `src/data/breeds.ts` і `src/data/breedingBreeds.ts`.
- Дані про препарати — `src/pages/Medicines/medicines.data.ts`.
- Журнал оновлень — `src/data/changelog.ts`.
- Тексти окремих матеріалів — у відповідних компонентах `src/pages/`.

Перед редагуванням карток перегляньте [опис їхньої структури](../Архітектура/sectionCards-structure.md). Для маршруту нової сторінки звіряйтеся з [мапою маршрутів](../Архітектура/approutes-map.md).

## Правила оновлення

1. Зберігайте українську мову й зрозумілі назви для читача.
2. Перевіряйте, що `path` картки відповідає зареєстрованому маршруту.
3. Не дублюйте матеріал, якщо його вже покриває інша сторінка або картка.
4. Для інформації про здоров’я зазначайте межі довідкового матеріалу: він не замінює огляд і призначення ветеринарного лікаря.
5. Після зміни контенту перевірте сторінку локально та виконайте `npm run build`, щоб оновилися sitemap і prerendered-сторінки.

## Зображення та посилання

Використовуйте локальні ресурси з `src/assets` або перевірені зовнішні джерела. Посилання мають вести на актуальний матеріал, а нове зовнішнє підключення слід зіставити з правилами CSP у `vercel.json`.

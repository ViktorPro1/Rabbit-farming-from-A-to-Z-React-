# Типові проблеми

## Застосунок повідомляє про відсутні Supabase-змінні

**Ознака:** помилка містить `Відсутні змінні оточення VITE_SUPABASE_URL / VITE_SUPABASE_ANON_KEY`.

**Рішення:** створіть `.env` на основі `.env.example`, заповніть обидва значення та перезапустіть Vite. Перевірка виконується у `src/lib/supabase.ts` під час запуску застосунку.

## Не працює або падає production build

**Перевірте:**

1. Чи встановлені залежності: `npm install`.
2. Чи задані обидві Supabase-змінні: пререндеринг під час `npm run build` потребує їх.
3. Чи проходить перевірка типів: `npx tsc -b --noEmit`.
4. Чи не додано в CSS `@import`.

Повна команда build спочатку генерує sitemap, потім запускає TypeScript і Vite-збірку з пререндерингом.

## Потрібна сторінка повертає 404 після деплою

Перевірте, що маршрут зареєстрований у `src/routes/groups/` і що його шлях потрапляє до відповідного списку пререндерингу, якщо сторінка має генеруватися статично. На Vercel fallback для SPA задає `vercel.json`; не прибирайте це правило без альтернативної конфігурації маршрутів.

## E2E-тести не стартують

E2E-набір використовує Chromium і production-preview на порту `4173`.

```bash
npm run build
npx playwright test
```

Якщо Playwright повідомляє про відсутній браузер, встановіть його командою `npx playwright install chromium`. Деталі сценаріїв — у [E2E.md](../Тестування/E2E.md).

## Після оновлення не видно нову версію сайту

Проєкт є PWA й використовує service worker. Оновіть сторінку, закрийте та відкрийте вкладку повторно; якщо проблема лишається, в інструментах розробника браузера перевірте стан service worker і кешу. Не вимикайте PWA-механізм без перевірки офлайн-сценарію з E2E-тесту.

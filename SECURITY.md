# Політика безпеки

Цей файл документує відомі вразливості проєкту, їхній статус і прийняті рішення.

## Відомі вразливості (npm audit)

### GHSA-qwww-vcr4-c8h2 — react-router-dom (CSRF bypass)

**Статус:** не застосовна до цього проєкту, залишена свідомо.

`npm audit` показує high-severity вразливість у `react-router-dom@7.18.1`
(CSRF bypass в RSC-режимі). Виправлення доступне лише в react-router
v8.3.0+ — мажорне оновлення з можливими breaking changes.

Вразливість стосується тільки застосунків, що використовують
нестабільні React Server Components (RSC) API. Цей проєкт —
клієнтський Vite SPA зі стандартним client-side роутингом,
RSC не використовується. Ризик відсутній.

**Рішення:** залишити на v7 до появи окремого приводу для міграції
на v8 (наприклад, потреба в нових функціях v8), а не заради самого
лише закриття попередження `npm audit`.

**Дата перевірки:** 2026-08-24
